# Getting help

- **Documentation:** <https://ahsan-muhd-444.github.io/house-price-prediction/>
  covers installation, a 5-minute quickstart, and the CLI, Python and REST guides.
- **Questions:** open a [question issue](https://github.com/Ahsan-muhd-444/house-price-prediction/issues/new?template=question.yml)
  or start a [discussion](https://github.com/Ahsan-muhd-444/house-price-prediction/discussions).
- **Bugs:** open a [bug report](https://github.com/Ahsan-muhd-444/house-price-prediction/issues/new?template=bug_report.yml)
  with the output of `amesml --version` and a minimal way to reproduce the problem.
- **Security problems:** see [SECURITY.md](SECURITY.md); please do not open a
  public issue.

This is a single-maintainer project maintained in spare time, so replies
usually take a few days.
